# 座標と単位

読み取りが返すのは数であり、その数が何に対する量かを述べる欄はどこにも無い。

以下は `標準描画` の設定項目について、1920x1080 のシーンへ一辺 100〜200 の図形を
置いて測った結果である。

## 原点は画面の中央で、1 は 1 ピクセル

実測: `X=0` `Y=0` の図形は `[860..1059] x [440..639]` を占めた。その中心 (959.5, 539.5)
は 1920x1080 の中央そのものである。

- `X=400` で中心が右へ 400 ピクセル動いた
- `Y=300` で中心が下へ 300 ピクセル動いた

**`Y` が増える向きは下である。**

## 拡大率は百分率で、100 が原寸

実測: `サイズ=200` の図形は `拡大率` 100 で 200 ピクセル、200 で 400 ピクセル、
50 で 100 ピクセルになった。

**`1.0` と書けば原寸の 100 分の 1 になる。** 値域（0〜10000）の内側であるため
書き込みは通る。

## 回転は度で、画面上の時計回りが正

実測: 一辺 200 の四角形へ `Z軸回転=30` を与えると、囲む矩形が 274 ピクセル四方に
なった。度として解いた 200×(cos30°+sin30°)=273.2 と一致する。

実測: 上を向いた三角形へ `Z軸回転=90` を与えると、頂点は右を向いた。上から右は
**画面上の時計回り**である。

値域は -3600〜3600 であり、10 回転ぶんを書ける。

## 中心は基準点で、動かすと絵は逆へ動く

`中心X` `中心Y` は、オブジェクトの中のどの点を `X` `Y` の位置へ置くかを決める。

実測: `中心X=50` で絵は左へ 50 ピクセル、`中心Y=50` で上へ 50 ピクセル動いた。
**指定した向きと逆である。**

実測: 同じ指定へ `Z軸回転=180` を重ねると、それぞれ右へ 50 ピクセル・下へ 50 ピクセル
へ移った。**回転が回るのはこの点のまわりである。**

置く位置を決めるのは `X` `Y` であり、`中心` はそこへ来る点を選ぶ。回転や拡大の軸を
ずらしたいときだけ触る。

## 縦横比は、縮む辺を符号が選ぶ

実測: 200x200 の図形へ `縦横比=50` を与えると 100x200 に、`-50` で 200x100 になった。
**正で横が、負で縦が縮む。** 長いほうの辺は変わらない。

`図形` の側にも同名の項目がある。**別の項目であり、値域は同じで小数桁が違う。**

## 透明度は透明さで、0 が不透明

実測: `透明度=75` で描いた画素は α=25% だった。0 で完全に見え、100 で消える。

**既定は 0 である。** 作ったばかりのオブジェクトが見えるのはそのためであり、
不透明にするために触る必要は無い。

## 測っていないもの

`X軸回転` と `Y軸回転` の向き、および奥行きの扱いは実測していない。
