# レイヤーの重なり

## 番号が大きいレイヤーが手前に描かれる

**AviUtl2 は番号が大きいレイヤーを手前に描く。** レイヤー 0 が最も奥であり、番号が増えるほど手前へ来る。

実測: 背景をレイヤー 1、タイトルをレイヤー 0 に置いて描画したところ、**背景がタイトルを覆った。**

## この規則は応答に現れない

レイヤーの一覧にも、オブジェクトの一覧にも、編集情報にも、前後関係を述べる欄は無い。応答が返すのは番号だけである。

そして**取り違えてもエラーは出ない。** 要求は成功し、値も要求どおりに入る。分かるのは描画したときだけである。

## 組むときの向き

奥から手前へ番号を増やす。

```
レイヤー 0: 背景
レイヤー 1: 図形・装飾
レイヤー 2: テキスト
```

先に置いたものが奥になるとは限らない——**決めているのは配置した順ではなく番号である。** 後から背景を足すなら、足す先はレイヤー 0 側であり、既にあるものの番号を上げる必要がある。

重ねた結果は描画して確かめる。[workflows.md](./workflows.md) を参照。
